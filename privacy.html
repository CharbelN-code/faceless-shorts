Privacy Policy

Last updated: 22 October 2026

Faceless Shorts is a private tool run by Charbel Nader. It uploads videos to his own YouTube channels. Only the channel owner signs in to it.

What data the app uses

When the owner signs in with Google, the app asks for two permissions:

  • Upload videos (youtube.upload): to upload the owner's own videos as private or scheduled.
  • View your YouTube account (youtube.readonly): to read the channel ID and name, so a video is never uploaded to the wrong channel.

The app does not read, change or delete any other videos, comments, subscribers or account settings.

Where data is kept

The sign-in token is stored only on the owner's own computer. The app has no server and no database online. No data is sold, shared or sent to anyone else.

How to remove access

Access can be removed at any time at myaccount.google.com/permissions. The owner can also delete the token file from their computer.

YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
